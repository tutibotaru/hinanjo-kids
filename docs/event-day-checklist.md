# 当日チェックリスト — 6/6(土) 本番

A4 1 枚で印刷して リーダー全員に 配ってください。
時刻は 開始時間からの 相対時間です(開始 = 0:00)。

---

## ⏰ -1:00(開始 1時間前) — 会場入り

- [ ] スマホ/タブレット 全台 起動・充電 100% 確認
- [ ] Wi-Fi 接続テスト(全端末で `hinanjo-kids.vercel.app` が開けるか)
- [ ] 受付ポスター(A3)を入口に貼る
- [ ] 班別のテーブル/エリアに **班カラーの目印** を置く
  - うけつけ 🟠 / おへやづくり 🟡 / たべものとみず 🔵 / けがびょうき 🔴
- [ ] 各班に **リーダー 1〜2名** + サポート 1名 を 配置
- [ ] 全リーダーがスマホで `/s/{コード}/manage` を 開ける状態にしておく

## ⏰ -0:30 — リーダー打ち合わせ(10 分)

- [ ] 班別ダッシュボードの 見方を 共有(緑/黄/赤)
- [ ] **⏸ いっせいストップ** ボタンの 位置を全員で 確認
- [ ] 担当決め:
  - 全体進行(司会): 1 名
  - 受付サポート: 2-3 名
  - 各班リーダー: 4 班 × 1-2 名 = 4-8 名
  - 救護: 1 名
  - 機材トラブル対応: 1 名

## ⏰ -0:15 — 子ども到着・受付開始

- [ ] 入口で **「ここで QR を読んでね」** と指さし
- [ ] 受付サポートは **スマホがない子を 共用タブレットへ** 誘導
- [ ] ニックネーム迷う子に「すきな食べ物でもOK」 と声かけ

## ⏰ 0:00 — 開始(司会あいさつ 5 分)

- [ ] 司会:「きょうは 4つのチームで 避難所を 立ち上げてみるよ」
- [ ] 「困ったら リーダーに 声をかけてね」
- [ ] 「📱 こうたい ボタンで 次の人に 渡そう」 と デモ

## ⏰ 0:05 〜 0:20 — フェーズ 0「はじめる(15ふん)」

- [ ] 各班リーダー: manage 画面で 班別ダッシュボード を 開く
- [ ] 🟡 黄色(50% 未満)の班 → 様子を見に行く
- [ ] 🔴 赤(困った発生)の班 → 即介入
- [ ] 8 割の班が ステップ完了したら **「つぎのフェーズ →」**

## ⏰ 0:20 — フェーズ進行を 全班に告知

- [ ] 司会:「次は 30分の 開設タイム!」
- [ ] manage で **「つぎのフェーズ →」** ボタンをタップ
- [ ] 「フェーズを 1 にかえたよ」 が出るのを 全員で確認

## ⏰ 0:20 〜 0:50 — フェーズ 1「ひらく(30ぷん)」

- [ ] 班別ダッシュボードを 5 分ごとに チェック
- [ ] 班間の協力(うけつけが きた人数を おへやに伝える等) を リーダーが促す

## ⏰ 0:50 — ふりかえりへ誘導

- [ ] 司会:「みんな、いったん 手をとめて。 ふりかえりを しよう」
- [ ] 各班リーダー: 班員を finish 画面に 誘導
- [ ] 「📝 きょう おぼえたこと」 を 1 文 書いてもらう

## ⏰ 1:00 〜 1:15 — 班ディスカッション

- [ ] 班ごとに 円になって 1 人ずつ 発表
- [ ] リーダーは ひろば(`posts`) で 全員のふりかえりを 開いておく

## ⏰ 1:15 — 修了証 + クロージング

- [ ] 各自 finish → **「🏅 しゅうりょうしょうを みる」** → 印刷/PDF保存
- [ ] スマホがない子は スタッフが代理印刷
- [ ] 司会:「本物の災害のときは リーダーや 大人の人と いっしょに 動こうね」

## ⏰ 1:30 — 解散・記念撮影

- [ ] 班ごとに 記念撮影
- [ ] 共用タブレット 回収

## 終了後

- [ ] manage で **「⏸ いっせいストップ」** にして 投稿を凍結(任意)
- [ ] ふりかえり投稿(`posts`)を スタッフが PC で確認
- [ ] 班別ダッシュボードの スクリーンショット を 報告書用に 保存
- [ ] 次回のため manage で **「ぜんぶ もとに もどす」** はしない(データ残す)

---

## 🆘 緊急時のフロー

1. **本物の災害発生** → 即 **⏸ いっせいストップ** → 全員 安全エリアへ
2. **怪我** → ⏸ ストップ → 救護担当へ
3. **体調不良** → 該当の子のみ 受付スペースで休む(他は継続)
4. **通信障害** → manage で確認 → リーダーの判断で 紙運用に切替
